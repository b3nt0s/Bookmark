# Flyer to Calendar Sync

Screens exported from the Stitch project "Flyer to Calendar Sync" (projects/8304035760037646638).

- `index.html` is the start page: the Sign in with Google screen. Its Google buttons go to the upload screen.
- `gallery.html` links every screen in flow order.
- `screens/` holds the other screens' HTML as Stitch generated it.
- `screenshots/` holds Stitch's rendered PNG of each screen.
